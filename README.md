## How to install a unsigned msix
(You can only install unsigned msixs on Windows 11 or higher with admin)

1. Open settings<img width="71" height="76" alt="image" src="https://github.com/user-attachments/assets/7d860e9b-b455-4466-9653-f32d4f617cce" />
2. Click System at the side bar<img width="301" height="42" alt="image" src="https://github.com/user-attachments/assets/fdb209df-6eaa-4d6a-be0b-bbd334c9445a" />
3. Click Advanced <img width="671" height="66" alt="image" src="https://github.com/user-attachments/assets/8c488c5a-6094-48c5-a64c-93524602bbff" />
4. Enable developer mode<img width="661" height="73" alt="image" src="https://github.com/user-attachments/assets/0b010aa7-896f-4a33-8c6d-67583e700a93" />
5. Open the unsigned msix file
6. Install
7. Optionally turn off developer mode again
